# Premier League Predictor and Analytics Dashboard

A comprehensive web application built with Streamlit and Python that predicts Premier League match outcomes using machine learning models while offering interactive player statistics, goal/assist leaderboards, and squad roster lookups.

## Getting Started

These instructions will get a copy of the project up and running on your local machine for development and testing purposes. See deployment for notes on how to deploy the project on a live system.

### Prerequisites

You need Python 3.9 or higher installed on your system along with pip package manager.

To check if Python is installed on your system, open your terminal and run:
```bash
python3 --version
