# Premier League Match Predictor & Analytics Hub ⚽

**A machine learning-powered match outcome predictor and interactive analytics dashboard for the Premier League**

This project lets users simulate any Premier League matchup and see win/draw/loss probability predictions, while also exploring team and player statistics through an interactive dashboard.

## Overview

Predicting football outcomes is normally left to guesswork or gut feeling. This project applies a trained machine learning model to historical match and performance data to generate probability-based predictions, wrapped in a dashboard that also lets users explore the underlying stats behind the numbers.

- **Simulate any matchup** — pick two clubs and get a win/draw/loss probability breakdown
- **Explore team performance** — browse historical results, goal differentials, and form
- **Browse player stats** — goal/assist leaderboards and squad rosters
- **View league standings** — current table with sortable columns
- **Visualize the data** — probability bar charts and performance trends

Data is sourced from public football statistics APIs and historical match datasets, cleaned and processed into features used by the prediction model.

---

## Features

### Match Prediction Engine
Select any two clubs and get a live win/draw/loss probability breakdown, generated by a scikit-learn model trained on historical match data and serialized with `joblib` for fast loading.

### Data Processing Pipeline
Raw match and player data is cleaned and transformed using Pandas and NumPy — handling missing values, engineering features (e.g. recent form, head-to-head history), and preparing inputs for the model.

### Interactive Analytics Dashboard
A multi-page Streamlit app featuring:
- Probability distribution bar charts for any matchup
- Team performance and form breakdowns
- Player goal/assist leaderboards
- League standings with CSV-based data management

## Getting Started

### Prerequisites

- **Python** >= 3.10
- **pip**
- **Git**

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/GDP90132/premier-league-predictor.git
cd premier-league-predictor
```

**2. Install dependencies**

```bash
pip install -r requirements.txt
```

`requirements.txt` should include at minimum:

```
streamlit
pandas
numpy
joblib
scikit-learn
```

**3. Add the dataset**

Place the raw match/player data files (CSV) into the `data/` folder. If a data-fetching or cleaning script is included, run it first to generate the processed dataset the model expects.

### Usage

**Run the app:**

```bash
streamlit run app.py
```

Then open the local URL Streamlit prints in your terminal (typically `http://localhost:8501`).
